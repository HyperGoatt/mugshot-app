# Sources, rights and cost

- Mugsy: existing approved `MugsyModelView`, `MugsyDesignSystem`, numeric rig
  curves and brand palette. Mugshot-owned artwork; no character replacement.
- Photography: existing `V3CreamyLatte` and `V3QuietCafeCorner` asset catalog
  images, reused as clearly fictional design fixtures. These are not new user
  photos or new claims about the owner's cafe visits.
- Type and icons: Apple system serif, system sans and SF Symbols through the
  existing Apple SDK. No new bundled font or icon dependency.
- Native authoring/render: local SwiftUI/UIKit, Xcode Simulator, native screen/video capture,
  Python standard library and Apple CLI tools. No hosted device subscription.
- Review encoding/contact sheets: existing local FFmpeg and Pillow. No binaries
  are redistributed; original sources and scripts are retained.
- Optional motion presentation: the already installed, pinned free local
  HyperFrames workflow; its retained license/cost record is in
  [the completion package](../../previews/completion-2026-10-30/LICENSES.md).

No paid generation credits, cloud rendering, subscription, paid export, royalty,
watermark or vendor splash. No new third-party asset generation is used.

The supplementary review board retains Inter/EB Garamond WOFF2 files and their
SIL OFL texts in `review/licenses`, plus the existing GSAP copyright/license header.
HyperFrames stays pinned to 0.8.185; only verified free local check/render commands
run. Native iOS uses only system fonts and never loads these review dependencies.
