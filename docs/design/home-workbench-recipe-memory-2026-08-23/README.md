# Mugshot Home Workbench — Recipe Memory Direction

This nine-screen production mockup is the visual source of truth for the revised Home Log a Sip journey.

## Happy path

1. **Choose context** — Select Home before any drink, photo, taste, or brew fields appear.
2. **Home Workbench** — Choose the coffee, method, gear, remembered recipe, and today's intended values.
3. **Brew this version** — Keep the active recipe glanceable and correct only actual values that changed.
4. **Capture the finished cup** — Add photos, select a cover, name the drink, and write the private memory.
5. **Rate the sip** — Reuse Mugshot's familiar Sip score and optional taste criteria.
6. **Compare and decide** — Compare with a prior attempt, review neutral deltas, and decide whether to repeat it.
7. **Save the result** — Always save the attempt privately; explicitly keep the recipe or create an immutable new version.
8. **Review and share** — Reuse the Mugshot publish flow while keeping post audience, raw note, and recipe visibility independent.
9. **Smart Brew Again** — Confirm what was saved and prefill the best remembered setup next time.

## Locked behavior

- Home starts with the brew; finished-cup photos and taste rating come afterward.
- Every technical field remains optional.
- The attempt is private and saved before sharing is considered.
- Mugshot summarizes differences without claiming that a variable caused the result.
- Recipe history is immutable; creating a better version never overwrites an older one.
- Smart Brew Again prefers the selected recipe and best attempt, then remembers coffee, method, gear, and unchanged values.
- Bag data, private notes, comparisons, and recipe visibility do not inherit the Mugshot audience automatically.

## Mock data

The continuous example uses Little Wolf Shantawene, Espresso, Recipe v3, Niche Zero, and Decent DE1. Current values are 18.5 g in, 40 g out, grind 17, 94 °C, 28 seconds, and a computed 1:2.2 ratio.
