# Mugshot Post V2 — Editorial Pour

Status: selected visual direction, awaiting final mockup approval before production implementation.

## Screen set

1. `01-canonical-full-post.png` — Complete default-collapsed Cafe post from hero through conversation.
2. `02-score-evidence-expanded.png` — Expanded personal score relationship, sip evidence, and cafe evidence.
3. `03-journal-visit-expanded.png` — Expanded shared journal note and safe visit context.
4. `04-conversation-composer.png` — Reactions, comments, replies, moderation entry points, and active composer.
5. `05-photo-viewer.png` — Full-screen multi-photo viewer and owner cover selection.
6. `06-no-photo-fallback.png` — Compact, deliberate Mugsy fallback for posts without usable media.

## Canonical post fields

- Author identity and avatar
- Audience and published date
- One or more photos with cover and carousel position
- Drink name
- Safe cafe or setting identity
- Mugshot score
- Supporting Sip and Cafe scores
- Public caption
- Capability-aware social actions
- Like and comment summary
- Taste and setting descriptor preview
- Optional tagged people
- Shared journal-note preview and visibility
- Safe visit context without a precise street address
- Reactions, comments, replies, and composer

## Interaction defaults

- The published caption and social actions appear before journal or scoring depth.
- `What shaped this Mugshot?`, the shared journal note, and visit context are collapsed by default.
- Mugshot is the primary score; Sip and Cafe are supporting evidence.
- The journal visibility is explicit and never broader than the post audience.
- Comments remain compact until the user opens the composer.
- Missing media uses the compact Mugsy memory panel instead of a full-height dark hero.

## Visual contract

- Cream page, foam surfaces, espresso typography, sage interaction states, and mint used sparingly.
- Editorial serif for the drink name and memorable prose; native iOS sans for metadata and controls.
- Authentic photography is the emotional center when media exists.
- Spacing and dividers establish hierarchy before cards, borders, or shadows.
- No trophy treatment, objective-review language, heavy gradients, or decorative passport clutter.
