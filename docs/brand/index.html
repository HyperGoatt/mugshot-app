Give it space

For web use, keep a quarter of the displayed icon width clear around a lockup. Retain the PNG's own padding, use a 12 px gap, and display the complete icon at 48 px or larger.

These are web application rules, derived from the existing mark and spacing system.

Use

Cream or white surfaces. Original proportions. The complete icon. A readable text signature.

Avoid

Recoloring, tracing, mirroring, stretching, cropping source padding, or inventing inverse and monochrome versions.

What the app does not supply

No approved standalone vector logo, inverse mark, monochrome master, CMYK master, or favicon-size redraw was found. Those are review gaps, not invitations to invent new brand assets. The original PNG remains the supplied master.

Display serif

Native: regular system serif with −0.2 pt tracking. Observed source sizes include 42 pt for the name, 40 pt for welcome, and 30 pt for screen headings.

Everyday sans

Native system sans for body copy, labels, and controls. On the web, begin at 16 px with comfortable line height. Preserve zoom, wrapping, and text growth.

-apple-system, BlinkMacSystemFont,
'Segoe UI', system-ui, sans-serif

The web stacks translate the native roles. System fonts vary by platform; fallbacks do not guarantee exact SF Serif parity. The PDF uses built-in Times and Helvetica for portability.

Meet Mugsy.

Same white ceramic mug. Same glasses. Same identity. Eighteen controlled poses, with new accessories and native code counterparts.

Welcome wave · current pose artwork

One character. A shared rig.

  • The original master is frozen, byte for byte.
  • Seven native body and face shapes stay locked.
  • Only pose, expression, gaze, liquid, and accessories vary.
  • Every image has a named SwiftUI configuration.
  • Prompts, hashes, alpha, margins, and optical review are recorded.

Generated illustrations and native previews share the same pose contract. They are different renderings; native geometry remains exact across every code pose.
