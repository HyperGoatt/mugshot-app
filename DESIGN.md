# Mugshot design authority

The [Mugshot brand kit](docs/brand/README.md) is the single source of truth for
identity, color, typography, imagery, voice, component translation, and brand
governance. Start there before creating or changing any Mugshot surface.

Use [brand.json](docs/brand/brand.json) for policy,
[tokens.css](docs/brand/tokens.css) / [tokens.json](docs/brand/tokens.json) for
generated design primitives, and [assets.json](docs/brand/assets.json) for exact
native artwork provenance and use restrictions. Do not duplicate these values
in this file. The [visual book](docs/brand/index.html) and
[website handoff](docs/brand/WEBSITE_HANDOFF.md) show their application.

The existing [Mugsy design subsystem](docs/MUGSY_DESIGN_SYSTEM.md) retains its
character construction and motion authority within the brand kit. Brand
documentation does not change native product behavior or release acceptance.
